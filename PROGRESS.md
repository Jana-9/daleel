## Phase 2 · Documents: done (2026-10-23)

Built:
- Backend: migration 0002 (documents, processing_jobs, document_chunks with HNSW index), PDF validation by content, local storage with server-generated keys, upload/list/get/file/delete/retry endpoints with owner-scoped queries (404 for other users' documents), worker with SKIP LOCKED claiming, stale-job recovery, limited retries, Arabic normalisation (NFKC, diacritics, alef/ya/ta marbuta), page-aware chunking with overlap and rectangles, local multilingual embeddings plus a fake for tests, truncation warning.
- Frontend: drag-and-drop upload with progress and instant client-side checks, document library with polling status badges, Arabic failure messages, open/retry/delete with an accessible confirm dialog.
- Sample: `samples/daleel-sample-guide.pdf`, fictional, generated by `backend/scripts/make_sample_pdf.py`.
- Tests: 66 backend tests (fake embeddings) + 5 optional real-model retrieval checks; 14 Playwright runs (7 scenarios × desktop and phone).

Verified locally: all of the above with the real model; sample PDF goes from upload to READY in about 3 seconds; file access returns 401 without a session; no horizontal scroll at 390px; danger button passes AA in both modes.

Decisions and findings:
- Embedding model chosen by Jana: free local model. Chunk size reduced from 900 to 450 after measuring the model's 128-token limit (3 of 4 sample chunks were being truncated).
- Real-model retrieval: 4 of 5 sample questions find the right page with vector search alone. The miss (dialect absence question) is kept as a strict xfail for Phase 3's hybrid search.

Not verified yet: GitHub Actions has not run on GitHub; `docker compose up` not started in the build environment.
